# 문제 커버리지 매트릭스

## 1. 판정 기준

판정 단위는 기능 이름이 아니라 `문제의 원인 + 결정 변수 + 책임/실행 위치/신뢰 경계`다.
기존 후보/채택 결과는 신규 후보의 입력으로 사용하지 않았다.
기존 결정 문서는 같은 결정축의 중복과 목록 불일치 확인에만 사용했다.

| 판정 | 의미 |
|---|---|
| `COVERED` | docs-align의 기존 문제 1~3과 같은 결정축에서 이미 다룸 |
| `NEW-DP` | 독립적인 원인/결정 변수/책임 경계를 가진 신규 문제 |
| `SUBDECISION` | 다른 DP 선택 뒤 정하는 protocol/interface/parameter/하위 구현 |
| `BASELINE-CONSTRAINT` | 모든 후보에 공통으로 적용할 고정 전제/gate |
| `DUPLICATE` | 이 매트릭스의 다른 신호 행에 같은 원인과 결정 변수가 있어 병합 |
| `EVIDENCE-ONLY` | PoC/시험/설명/ID 충돌 자료로서 결정 문제가 아님 |
| `OUT-OF-SCOPE` | 현재 Secure Vision AI Framework 경계 밖 |
