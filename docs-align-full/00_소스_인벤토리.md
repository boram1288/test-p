## 2. 판독 방법과 근거 사용 규칙

- Markdown은 제목/요구 표/문제 상황/결정 질문/TBD/미해결/제외 문구를 텍스트로 판독했다.
- DOCX는 OOXML 목록과 `word/document.xml`을 추출해 Markdown Use Case와 대조했다. 내장 이미지는 thumbnail 1개뿐이며 별도 아키텍처 도식은 없다.
- 본편 35개 파일(슬라이드 1~33과 소문자 확장자 변형 1/6), appendix 17개, 인포그래픽 3개와 `docs-dp/DP-01-배경.png`를 contact sheet로 전수 시각 검토했다.
- G-01~G-10에 직접 연결되는 본편 31~32, appendix 10~15와 `DP-01-배경.png`는 원본 해상도로 재검토했다.
- 기존 후보/결정 문서는 신규 후보 생성의 입력으로 쓰지 않는다. 결정축 중복과 실현 가능성 누락 대조에만 사용한다.
- `시각 검토(contact sheet)`는 해당 원본을 축소 배치해 존재/슬라이드 번호/주제/중복 여부를 확인했다는 뜻이다.

## 6. 판독 제한과 후속 추적

- 이미지의 작은 본문은 원본 시각 검토 대상 9개를 제외하면 contact sheet에서 주제/ID/문제 문장 수준으로 판독했다. 세부 문구 인용은 연결된 Markdown 원문을 우선한다.
