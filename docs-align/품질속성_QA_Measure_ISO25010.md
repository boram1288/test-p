# 품질 속성(QA)과 Measure 재정의

## 1. 목적

본 문서는 `SW_Architect_개인과제/슬라이드9.PNG`의 기존 QA를 다음 세 가지 문제와 정렬하여 다시 정의한다.

1. HW 공유 시 기밀 데이터 노출
2. 강한 메모리 격리로 인한 pVM 간 대용량 데이터 전달 문제
3. pVM 수명에 종속된 암호화 파일 유실

품질속성 명칭은 [ISO/IEC 25010:2023 제품 품질 모델](https://www.iso.org/standard/78176.html)을 기준으로
정렬한다. Measure는 [ISO/IEC 25023:2016](https://www.iso.org/standard/35747.html)의 취지에 맞춰
관찰값, 계산식, 단위, 시험조건과 판정기준을 분리한다.

ISO/IEC 25010은 품질 특성과 하위 특성을 분류하는 기준이며 제품별 합격 임계값을 정해 주지는 않는다. 따라서
`0회·0건·100%`처럼 세 문제의 불변조건에서 직접 도출되는 값만 확정 기준으로 사용하고, 근거가 부족한 시간과
자원 상한은 잠정 목표 또는 TBD로 표시한다.

설계 제약 QA 2개로 구성하는 것이 세 문제와의 추적성이 명확하다.

## 3. QA, Measure와 설계 Gate의 구분

- **QA:** 제품이 지속해서 만족해야 할 품질 특성이다.
- **Measure:** QA 충족 여부를 판단하기 위한 관찰값과 계산식이다.
- **설계 Gate:** 특정 설계 원칙의 준수 여부를 판정한다. 예를 들어 `실제 프레임 memcpy 0회`는 zero-copy 준수
  Gate이며, 메모리 사용량 자체를 나타내는 Measure는 아니다.
- **확정:** 문제 문서의 불변조건이나 정량 기준에서 판정값을 직접 도출할 수 있다.
- **잠정/TBD:** 측정은 가능하지만 목표값의 제품·HW 근거가 더 필요하다.
- **Blocked:** Measure와 목표는 정의됐으나 검증 메커니즘 같은 선행조건이 아직 정해지지 않았다.

보안 관련 판정은 비신뢰 Host의 로그만으로 증명하지 않는다. 신뢰 계층의 이벤트 trace, SMMU/S2MPU 권한
snapshot, 외부 계측 또는 침투시험 결과를 사용한다.

## 5. Measure 상세

### QA-01 성능 효율성 — 시간 반응성·용량

기존의 단일 반환시간을 문제 원인별 구간으로 분해한다. 제품 종단 지연은 별도로 유지하되, 원인 분석에는 구간별
Measure를 사용한다.

| Measure | 대상 | 관찰값과 계산식 | 단위 | 시험조건 | 판정기준 |
|---|---|---|---|---|---|
| M-01a HW 전환 지연 | 문제 1 | `T_hw = t(새 소유자 권한 부여 완료) - t(신규 요청 차단 시작)`의 평균·p95·p99·최댓값 | ms | 정상 전환과 DMA timeout, pVM 강제종료, 초기화 실패를 분리하여 반복 측정 | TBD. HW별 frame budget에서 허용 몫을 확정한 뒤 설정 |
| M-01b 프레임 전달 지연 | 문제 2 | `T_transfer = t(AI pVM 접근 가능) - t(Camera 쓰기 fence 완료)`의 평균·p95·p99·최댓값 | ms | 1080p RGB24, 30 fps 지속 입력, 정상상태와 오류주입을 분리 | TBD. pVM 간 전달 구간 예산을 먼저 할당 |
| M-01c 지속 처리 용량 | 문제 2 | `처리 fps = AI 전달 완료 frame 수 / 측정시간`, `유실률 = 유실 frame 수 / 생성 frame 수 × 100` | fps, % | 1080p RGB24 30 fps를 10분 이상 지속하고 동일한 warm-up·부하 조건 적용 | 처리량 30 fps 이상, 유실률 0%. 지연 상한은 TBD |
| M-01d 저장 재연결 cold start | 문제 3 | `T_start = t(Workload 서비스 준비) - t(pVM 생성 시작)`의 평균·p95·최댓값 | s | 저장소 정상·부하·재시도 조건을 분리하여 재생성 반복 | p95 2초 이하 **잠정 목표**. 근거 보완 필요 |
| M-01e 제품 종단 지연 | 전체 | `T_e2e = t(Host가 판단 결과 수신) - t(Camera frame timestamp)`의 p95·p99 | ms | AI 추론을 포함한 실제 제품 경로. 구간별 timestamp를 함께 수집 | TBD. 기존 10 ms는 포함 구간과 근거가 불명확하므로 승계하지 않음 |

### QA-04 보안성 — 무결성 및 접근권 강제

ISO/IEC 25010의 독립 하위 특성으로 `접근통제`를 추가하는 것이 아니라, 기밀성과 무결성을 보장하는 과제 전용
실패 메커니즘으로 명시한다.

| Measure | 대상 | 관찰값과 계산식 | 단위 | 시험조건 | 판정기준 |
|---|---|---|---|---|---|
| M-04a HW 권한 중복 부여 | 문제 1 | `중복률 = 둘 이상의 주체에 MMIO 또는 DMA 권한이 동시에 유효한 전환 수 / 전체 전환 수 × 100` | % | 정상·timeout·강제종료·요청폭주 전환 | 0% |
| M-04b 비인가 pVM buffer 접근 | 문제 2 | `성공 건수`, `차단률 = 차단 시도 / 전체 비인가 시도 × 100` | 건, % | 허용하지 않은 pVM, access mode, generation으로 CPU·DMA 접근 시도 | 성공 0건, 차단률 100% |
| M-04c Workload 저장 공간 오연결 | 문제 3 | 위조·재사용 식별자로 다른 Workload의 volume 연결 또는 읽기·쓰기까지 성공한 건수 | 건 | 정상 요청과 위조·교차 Workload 요청을 함께 반복 | 0건 |
| M-04d 삭제·변조·되돌리기 검출 | 문제 3 | `검출률 = 탐지된 주입 공격 수 / 전체 주입 공격 수 × 100` | % | 파일 삭제, bit 변조, 과거 정상 암호문·metadata 교체 | 목표 100%. **Blocked:** 비-RPMB 검출 메커니즘 정의 선행 |

### QA-05 기능 적합성 — 기능 정확성 / 신뢰성 — 무결함성(Faultlessness)

보안 Measure는 비인가 접근이 성공했는지를 판정하고, 신뢰성 Measure는 내부 상태기계가 정의된 전이를 정확히
수행했는지를 판정한다. 상태 전이가 사양과 일치하는지는 기능 정확성에, 운용 중 전이 실패 없이 동작하는지는
무결함성에 대응하므로 두 하위 특성에 함께 매핑한다. 같은 trace를 사용할 수 있지만 보안 판정과 상태 전이 판정의
predicate는 다르다.

| Measure | 대상 | 관찰값과 계산식 | 단위 | 시험조건 | 판정기준 |
|---|---|---|---|---|---|
| M-05a HW 전환 순서 위반 | 문제 1 | `위반률 = 필수 전환 순서를 벗어난 전환 수 / 전체 전환 수 × 100` | % | `요청 차단→DMA 정지→drain→회수→소거→부여` 이벤트 trace 검사 | 0% |
| M-05b buffer 상태·generation 불일치 | 문제 2 | 허용되지 않은 상태 전이, 중복 반환, 오래된 generation 수용 건수 | 건 | 정상, 순서역전, 중복반환, timeout과 pVM 재시작 | 0건. `FREE`와 `RECLAIMING`의 무소유 상태는 위반에서 제외 |

## 6. Measure 실행 공통 규칙

1. `N`과 시험시간은 통계적 신뢰도, HW 변동성과 오류 주입 종류를 근거로 시험계획에서 확정한다.
2. 평균만 사용하지 않고 p95·p99·최댓값과 원시 표본 수를 함께 기록한다.
3. 정상 경로와 오류 주입 경로를 섞어 하나의 평균으로 만들지 않는다.
4. 성능 비교 시 입력 format, fps, cache 상태, background load, pVM 수와 warm-up 시간을 동일하게 유지한다.
5. 보안 차단률은 비인가 시도 수가 0이면 계산하지 않는다. 사전에 정의한 공격 시도를 반드시 실행한다.
6. 복구 성공은 단순 mount가 아니라 권한, 최신 version, 내용 hash와 상태기계 정합성까지 확인한다.
7. 보안성과 신뢰성에서 같은 trace를 사용하더라도 접근 성공 여부와 상태 전이 오류를 별도 집계한다.
8. 잠정 목표는 PoC baseline과 제품 SLO가 확정되면 설계 승인 전에 확정값으로 승격한다.
