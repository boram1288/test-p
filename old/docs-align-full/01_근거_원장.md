# 근거 원장

## 1. 목적과 사용 규칙

이 원장은 현재 구조/요구사항/품질 시나리오/제약/PoC 관찰에서 원자 근거를 추출한다.
기존 후보와 채택 결과는 신규 후보의 입력으로 사용하지 않는다.
기존 결정 문서는 결정축 중복/목록 불일치/실현 가능성 누락을 대조할 때만 사용한다.

- 근거 ID는 `E-NNN`으로 고정한다.
- 원문 ID는 바꾸지 않고 문서 계열을 드러내는 정규화 ID를 병기한다.
- 신뢰도 `높음`은 현재 요구/QAS/직접 시각 관찰/명시적 미해결 문구다.
- 신뢰도 `중간`은 제한 PoC/기술 조사/기존 결정축 대조다.
- PoC는 관찰 사실만 사용하며 실제 제품 환경 대표성을 별도로 기록한다.
- 모든 근거 ID는 `02_문제_커버리지_매트릭스.md`의 한 행 이상에서 참조해야 한다.
